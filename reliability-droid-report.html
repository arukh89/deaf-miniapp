Alert Investigation – Donation does not trigger Warpcast Wallet overlay

SEV-3 Started: 2025-12-02 00:00:00 UTC
On-call: Second Miniapp

Executive Summary

Donation clicks in the Farcaster mini app intermittently open a deeplink instead of the in-app wallet sheet. The app does not use the Mini App SDK wallet provider or the official Wagmi connector, so the Warplet provider is often not detected and the code falls back to a URL open.

Root Cause Analysis

Suspected root cause:

  • Primary Hypothesis: Missing usage of sdk.wallet.getEthereumProvider() and the @farcaster/miniapp-wagmi-connector. Current provider discovery relies on window.ethereum/EIP‑6963 and Wagmi's generic injected() connector.
  • Contributing Factors: Fallback to Warpcast deeplink (/~/send) in DonationSection.tsx masks the failure by opening a web URL instead of the native wallet sheet.

Evidence

Code Reference

src/lib/miniappProvider.ts (no SDK provider call):

const eth: any = (window as any).ethereum
if (eth?.providers?.length) { /* ... */ }
// No sdk.wallet.getEthereumProvider() call

src/providers/WagmiProviders.tsx (uses generic injected connector):

connectors: [injected()], // not the Farcaster Mini App connector

Docs guidance: Farcaster Mini Apps – Interacting with wallets recommends sdk.wallet.getEthereumProvider() and @farcaster/miniapp-wagmi-connector.

Cause → Effect

Because provider discovery uses generic injection instead of the Mini App SDK, when running inside Warpcast the app often cannot resolve the Warplet provider → the donation handler falls back to opening a deeplink, so no in‑app “Review Transaction” sheet appears.

Proposed Fix

  1. Immediate Mitigation: Prefer the Mini App provider before falling back.
    Patch src/lib/miniappProvider.ts:
    const { sdk } = await import('@farcaster/miniapp-sdk')
const p = await sdk.wallet.getEthereumProvider().catch(() => null)
if (p) return p
// fallback to window.ethereum / EIP-6963
  2. Short-term Fix: Switch Wagmi to the official connector.
    Install: pnpm add @farcaster/miniapp-wagmi-connector
    Update src/providers/WagmiProviders.tsx:
    import { farcasterMiniApp as miniAppConnector } from '@farcaster/miniapp-wagmi-connector'
const config = createConfig({ chains: [base], transports: { [base.id]: http() }, connectors: [miniAppConnector()] })
  3. Long-term Solution: Use Wagmi hooks (useSendTransaction/writeContract or useSendCalls for EIP-5792 batches) so transactions consistently open the Warplet sheet; keep sdk.actions.openUrl only as a final fallback for non-miniapp browsers.
    Validation: In Warpcast mini app, tapping “Donate $1 USDC” shows the Review Transaction sheet with network Base and from “Warpcast Wallet”.
